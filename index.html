Why a gate

Most copy fails because it only optimises one or two layers. Sales-only copy is hollow. Jung-only copy doesn't convert. SEO-only copy reads like a robot. AI-SEO-only copy gets cited but doesn't move anyone. The gate forces every layer to clear its bar before the copy ships.

The gate doesn't write for you. It tells you where you're hedging.

The 6-Layer Copy Gate

Standing order. Every piece of copy clears these six before shipping.

Layer 1 · Jung

Which archetype does the audience occupy right now? Which shadow does your copy invite them to face? Pick one — Hero, Sage, Lover, Caregiver, Outlaw, Ruler, Seeker, Creator — and write in it, not at it. Bonus move: name the shadow before they do. Disarms defence.

Layer 2 · Freud

Three layers of want:

id        what they actually want       (desire, recognition, belonging)
ego       what they say they want       (the rationalized version)
superego  what they think they should   (the moralized version)

aim copy at the GAP between the three.
name the displacement.

Layer 3 · Sales 101

The structural skeleton. Hook → Stakes → Specificity → Social proof → Scarcity → Authority → Reciprocity → Consistency → Liking → Clear CTA → Earned urgency. Frameworks: Pain–Agitate–Solve · Problem–Promise–Proof · AIDA. Rule: every claim survives the "so what" test.

Layer 4 · SEO

Traditional search: primary keyword + 3–5 semantic neighbours · search intent named · H1/H2/H3 with target terms · internal + external links · meta description under 160 chars · alt text · schema markup where applicable.

Layer 5 · AI-SEO / GEO / AEO

The new layer. LLMs cite copy that is structured for extraction:

· facts attributable to named entities
· table / list formatting LLMs love to pull
· "according to X" attributable claims
· recency signals (dates, "as of")
· expertise markers (credentials, methodology)
· semantic clarity over keyword stuffing
· optimize for "what is X" / "how does X work" / "X vs Y"

Layer 6 · Platform

LinkedIn    1300 char sweet · line breaks · no hashtag stuffing
X/Twitter   hook in first 7 words · thread or single-punch
Blog        1500–2500 words · TOC · skim-readable subheads
Email       subject <50ch · preheader · single CTA · scan
Landing     above-fold value · proof block · social · CTA repeat
README      two-audience · user CTA first · dev architecture second
